# Energy Job Radar

A static GitHub Pages job-search dashboard with an automatic GitHub Actions updater. The app is tailored for full-time opportunities related to petroleum engineering, geothermal energy, reservoir engineering, production analysis, subsurface analytics, CCS/CCUS, hydrogen storage, renewable energy, and energy data science.

## What is new in this expanded version

This version expands beyond Adzuna and USAJOBS. The updater now checks:

1. **Adzuna** — broad job aggregation; requires `ADZUNA_APP_ID` and `ADZUNA_APP_KEY`.
2. **USAJOBS** — federal jobs; requires `USAJOBS_EMAIL` and `USAJOBS_API_KEY`.
3. **Greenhouse job boards** — public company career-board feeds; no API key required.
4. **Lever postings** — public company job feeds; no API key required.
5. **Remotive** — remote roles; no API key required.
6. **Arbeitnow** — public global/Europe job API; no API key required.
7. **Company Watchlist** — direct links to important employer career pages when no clean API is available.

The app still excludes internships, co-ops, student trainee roles, and similar postings.

## Main files

```text
index.html                         Site layout

config/profile.json                Your keywords, scoring terms, full-time search queries
config/source_targets.json         Greenhouse/Lever/company career-page targets
config/company_watchlist.json      Side-panel company links; regenerated by the updater
data/jobs.json                     Job data consumed by the site
.github/workflows/update-jobs.yml  Daily GitHub Actions update workflow
```

## Required GitHub Secrets

You only need secrets for Adzuna and USAJOBS. Greenhouse, Lever, Remotive, and Arbeitnow do not require secrets.

Add these in:

```text
Settings → Secrets and variables → Actions → New repository secret
```

Required names:

```text
ADZUNA_APP_ID
ADZUNA_APP_KEY
USAJOBS_EMAIL
USAJOBS_API_KEY
```

## How to update the live site

After replacing files in GitHub:

1. Go to **Actions**.
2. Click **Update job postings**.
3. Click **Run workflow**.
4. Wait for the green check.
5. Open `data/jobs.json` and confirm that real postings replaced the sample data.
6. Refresh the GitHub Pages site.

## How to customize search terms

Edit:

```text
config/profile.json
```

The most useful sections are:

- `queries`: broad search phrases for Adzuna.
- `federal_queries`: shorter keywords for USAJOBS.
- `remote_queries`: terms for remote/data-oriented sources.
- `positive_keywords`: skills and domain terms that increase fit score.
- `negative_keywords`: terms that lower fit score.
- `excluded_keywords`: hard exclusions. Internships and co-ops are already excluded.

## How to add more companies

Edit:

```text
config/source_targets.json
```

For Greenhouse:

```json
{ "company": "Company Name", "board": "greenhouse_board_token", "focus": "Why this company matters" }
```

For Lever:

```json
{ "company": "Company Name", "site": "lever_site_name", "focus": "Why this company matters" }
```

For companies without a clean API feed, add them to `company_search_fallbacks` with a direct career URL.

## Notes

Some Greenhouse and Lever tokens can fail if a company changes applicant-tracking systems or uses a different board token. The updater skips failed boards automatically and records warnings in `data/jobs.json` under `metadata.source_errors`.

The sample jobs in `data/jobs.json` are preview data. They disappear after the GitHub Actions workflow successfully fetches live postings.


## Houston oil-and-gas company watchlist and recency update

This version adds a Houston oil-and-gas watchlist based on the EasyLeadz Houston company list provided by the user. The watchlist is stored in:

- `config/houston_oil_gas_watchlist.json`
- `config/company_watchlist.json`
- `config/source_targets.json`

The app does not blindly scrape every employer website. It captures postings automatically only where an API-friendly source exists: Adzuna, USAJOBS, Greenhouse, Lever, Remotive, and Arbeitnow. Companies without clean job feeds are included as career-page or Google-search fallback links so you can still check them directly from the dashboard.

### Recent posting filter

The updater now filters out stale postings. Default settings are in `config/profile.json`:

```json
"min_posted_date": "2026-01-01",
"max_job_age_days": 120,
"include_undated_jobs": false
```

This prevents old 2025 postings from appearing in the matched jobs list.

### Back-to-top button

The dashboard now includes a floating `↑ Top` button that appears after scrolling and returns the user to the top of the page.
